# Parkuhr PWA

Kleine Progressive Web App zum Einstellen einer Parkuhr mit Countdown.

## Funktionen

- Parkzeit in Minuten einstellen
- Warnzeit vor Ablauf einstellen
- Optionaler Hinweis, z. B. Parkplatz oder Parkscheinzeit
- Sichtbare Warnmeldung im Bildschirm vor Ablauf
- Meldung bei Ablauf der Parkzeit
- Pause und Zurücksetzen
- Offline nutzbar durch Service Worker
- Installierbar als PWA auf Smartphone oder Desktop

## iPhone Installation

1. Link in Safari öffnen
2. Teilen-Symbol antippen
3. "Zum Home-Bildschirm" auswählen
4. Namen bestätigen

## Hinweis zu Benachrichtigungen

Die App zeigt immer eine Warnung im Bildschirm an, solange die App geöffnet ist. Browser-Benachrichtigungen können je nach Gerät, Browser und iOS-Version eingeschränkt sein.
